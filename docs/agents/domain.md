# Domain Documentation

## Layout
This repository uses a **single-context** layout.

## Structure
- `CONTEXT.md`: The primary source of truth for the repository's domain, architecture, and operational context.
- `docs/adr/`: Contains Architecture Decision Records (ADRs) documenting significant design choices.

## Consumer Rules
- Always check `CONTEXT.md` before starting new tasks or making architectural changes.
- When proposing a significant change, a new ADR should be created in `docs/adr/`.
