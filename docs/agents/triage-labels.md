# Triage Labels

The following labels are used for the triage workflow:

- `needs-triage`: New issues requiring initial assessment.
- `needs-info`: Issues awaiting clarification from the reporter.
awaiting clarification from the reporter.
- `ready-for-agent`: Issues ready to be processed by an automated agent.
- `ready-for-human`: Issues requiring human intervention or review.
- `wontfix`: Issues that have been closed without action.
